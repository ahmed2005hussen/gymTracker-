# Hadidy image assets

Place your image files in this folder with these names to populate the redesigned dashboard:

- `dashboard-hero.jpg` — large dashboard hero image
- `workout-plan.jpg` — workout plan card image
- `diet-plan.jpg` — diet plan card image
- `supplement.jpg` — supplement card image

The dashboard has dark gradient fallbacks, so it remains usable until you add these files. You can use PNG or WebP instead, but then update the corresponding paths in `Dashboard.html` or `style.css`.
